# SN_Claude_sep2026
## Expense Tracker

Two versions of the same simple expense tracker:

- **Python:** `expense_tracker.py`. Run it with `python expense_tracker.py`.
  Column A = amount, column B = expense name, plus the balance after each expense. Negative amounts are not allowed.
  Row 1 holds the starting balance (1000). Your data is saved to `expenses.json`.
- **Webpage:** open `index.html` in a browser.
