# SN_Claude_sep2026
## Expense Tracker

Two versions of the same simple expense tracker:

- **Python (Excel style):** `expense_tracker.py`. Run it with `python expense_tracker.py`.
  Column A = amount, column B = expense name, column C = balance.
  Row 1 holds the starting balance (1000). Your data is saved to `expenses.json`.
- **Webpage:** open `index.html` in a browser.
